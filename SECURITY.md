# Security reporting

Report suspected vulnerabilities using
[GitHub's private vulnerability reporting form](https://github.com/fantastic-octo-barnacle/herkules/security/advisories/new).
Include the affected component or commit, reproduction steps, and expected impact.
Do not include live credentials, personal data, or production database exports.

Please avoid public issues or pull requests that disclose an unaddressed
vulnerability. General bugs and documentation improvements can use normal issues
and pull requests.

Herkules is actively developed. There is no maintained release-support matrix;
include your exact commit when reporting a problem. Existing defects and design
gaps are tracked in [KNOWN_ISSUES.md](KNOWN_ISSUES.md).
