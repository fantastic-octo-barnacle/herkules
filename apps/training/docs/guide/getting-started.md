# 课程与实验

这里是 Herkules 的交互式学习空间。你只需要浏览器；Rust 演示通过官方 Rust Playground 编译运行。

## 推荐顺序

1. **[PID 调参](/labs/pid)**：认识误差、比例、积分、微分和输出限幅。先观察，再试着解释。
2. **[Rust 控制器](/labs/rust)**：把一个简单的反馈规则写成函数，运行它，并检查输出边界。

## 实验中的约定

- PID 实验是理想化的二阶系统，不代表真实电机的全部特性。实验参数不能直接复制到机器人上。
- 调参只在你的浏览器中计算，不会连接真实硬件。
- Rust 代码只有在你打开 Playground 链接时才会发往该站点；此站点不编译或保存代码。
- 刷新页面会恢复示例。当前没有账号、成绩、提交记录或后台执行队列。

## 接下来可以探索

在同一组参数下改变执行器限幅，观察积分饱和。在重力作用下，比较只有比例控制和加入积分后的最终误差。回到 Rust 实验，用测试描述你希望控制器保证的行为。
