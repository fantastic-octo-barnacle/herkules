# PID：让输出追上目标

目标位置从 0 跳到 1。先点击「观察振荡」，再点击「加入微分」，比较两条响应的超调与稳定过程。

## 三个参数，三个问题

| 参数          | 它在看什么           | 试一试                          |
| ------------- | -------------------- | ------------------------------- |
| **Kp · 比例** | 现在离目标有多远？   | 增大 Kp，观察速度和超调如何变化 |
| **Ki · 积分** | 误差已经积累了多久？ | 加入负载，再用 Ki 消除持续误差  |
| **Kd · 微分** | 位置变化得有多快？   | 在振荡预设中逐渐增大 Kd         |

## 为什么要限制积分？

把输出限幅调到 2，再增大 Ki。执行器已经无法增加输出，积分却可能继续积累。切换「抗积分饱和」，比较系统响应。本实验在输出饱和且误差使饱和加重时暂停积分。

## 模型与读数

模型为 `x'' = u − 1.2x' − 2x + d`，质量为 1，目标为 1。负载 `d` 在第 6 秒加入。采用 5 ms 固定步长的半隐式 Euler 积分，微分项使用位置变化率以避免目标阶跃引起微分突变。

超调是整段实验中高于目标的最大百分比。「进入 ±2% 区间」是最后一次离开误差带之后的时刻，并要求至少保持 0.5 秒；有负载时，这个读数也包含负载后的恢复过程。12 秒误差是有限时间读数，不一定等于稳态误差。
