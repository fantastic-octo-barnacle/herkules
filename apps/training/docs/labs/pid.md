# PID：让输出追上目标

云台从水平、零偏航开始，追踪设定的偏航与俯仰角度。先点击「观察振荡」，再点击「加入微分」，比较两条响应的超调与稳定过程。

## 三个参数，三个问题

| 参数          | 它在看什么           | 试一试                             |
| ------------- | -------------------- | ---------------------------------- |
| **Kp · 比例** | 现在离目标有多远？   | 增大 Kp，观察速度和超调如何变化    |
| **Ki · 积分** | 误差已经积累了多久？ | 观察重力下的下垂，再用 Ki 减小误差 |
| **Kd · 微分** | 位置变化得有多快？   | 在振荡预设中逐渐增大 Kd            |

## 为什么要限制积分？

把输出限幅调到 2，再增大 Ki。执行器已经无法增加输出，积分却可能继续积累。切换「抗积分饱和」，比较系统响应。本实验在输出饱和且误差使饱和加重时暂停积分。

## 模型与读数

俯仰角 θ 从水平向上为正，偏航角 ψ 绕竖直轴旋转。两轴各自运行 PID，共用上方的增益与力矩限幅，内部角度单位为弧度，图表显示角度。

- 俯仰：`I θ'' = u_pitch − b θ' − m g l cos(θ)`。
- 偏航：`I ψ'' = u_yaw − b ψ'`。
- 教学参数：`I = 1 kg·m²`，`b = 1.2 N·m·s/rad`，`m = 1 kg`，`l = 0.3 m`，`g = 9.81 m/s²`。载荷重心位于俯仰轴前方，重力从第 0 秒持续作用，没有定时扰动。

采用 5 ms 固定步长的半隐式 Euler 积分。微分项使用角速度，以避免目标阶跃引起微分突变。未模拟轴间惯性耦合、碰撞、机械限位或重力前馈补偿；几何为示意图。

实验持续运行，没有结束时刻。调整目标、增益、力矩限幅或预设均保留当前角度、角速度与积分状态，从下一步开始使用新参数。曲线滚动显示最近 12 秒；下方显示当前两轴误差和俯仰力矩。

「暂停」冻结状态，可在暂停时调整参数，再点击「继续」。「恢复默认参数」只恢复调参值；「重置状态与曲线」才会将角度、速度、积分、时间和历史清零，并保留当前参数。浏览器在后台限制更新频率时，仿真会放慢，不追赶后台经过的时间。

## 看重力如何影响控制

先将三个增益设为 0，观察载荷向下落。再选择「仅比例 + 阻尼」，观察俯仰轴为何停在目标下方。加入积分后，控制器逐渐积累抵消重力所需的力矩。将俯仰目标设为 0°：即使只是保持水平，电机也需要持续输出力矩。

蓝色竖杆绕自身的偏航轴转动，绿色杆从竖杆顶端向前伸出，并绕顶端的俯仰轴上下转动，红色箭头表示重力，金色标记表示目标方向。图表与模型使用同一组仿真角度；模型始终显示当前姿态，图中保留目标变化前后的响应，方便观察连续调参的效果。
