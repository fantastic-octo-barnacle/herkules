# Rust：把反馈写成函数

下面是一个带输出限幅的比例控制器。改变 `kp`，在 Playground 中运行，观察每一步的位置与输出。

<ClientOnly><RustLab /></ClientOnly>

## 做三个小实验

1. 把 `kp` 从 `2.0` 改为 `0.5`，预测位置接近目标的速度。
2. 把目标从 `1.0` 改为 `-1.0`，确认输出方向正确。
3. 在 Playground 的运行菜单中选择 **Test**，运行限幅测试。然后去掉 `.clamp(...)`，观察测试如何失败。

## 这个程序模拟了什么？

每一步使用 `position += output * 0.1`，相当于用速度指令驱动位置的一阶积分模型。它用于理解反馈与测试，**和 PID 页面的二阶弹簧阻尼模型不同**，两页参数不应直接比较。

## 执行位置

当前演示在官方 Rust Playground 中编译运行。编辑器支持语法高亮；没有本地编译器或 Rust 语言服务器。代码通过链接传给 Playground，请只使用练习代码。

未来的站内练习会通过隔离的编译服务返回诊断和测试结果；需要交互仿真的控制器可以编译为 WebAssembly 后在浏览器执行。
